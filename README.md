# Laboratorio de Instrumentos de Investigación de Mercados

Sitio estático para construir instrumentos de recolección de datos.

## Técnicas incluidas
- Encuesta / cuestionario
- Entrevista semiestructurada
- Focus Group / guía de moderación

## Uso local
Abre `index.html` en el navegador.

## Publicar en GitHub Pages
1. Sube `index.html`, `styles.css` y `app.js` a un repositorio.
2. Ve a Settings > Pages.
3. Selecciona Deploy from a branch.
4. Elige `main` y `/root`.
5. Guarda.

La información escrita por el estudiante se conserva en el navegador mediante `localStorage`.
